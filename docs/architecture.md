# NeighborHelp

NeighborHelp is a local community task exchange focused on everyday services, trust, and safety.

## Product goals

- make it easy to post and discover nearby tasks
- keep location privacy first
- allow trusted negotiation through offers and match acceptance
- support messaging after match acceptance
- build a trusted local platform with reviews and safety signals

## Safety model

- approximate location only in public listings
- no exact address shown before acceptance
- exact location only after a valid match is accepted
- messaging and offers happen in-app
- reviews help build trust over time

## Milestones

1. auth + user identity
2. task posting + nearby discovery
3. offers + match acceptance
4. messaging + review flow
5. moderation and safety rules
